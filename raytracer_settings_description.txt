In this file is a list of all of the settings that go in to the raytracer and a description of each.

For most, I'd reccommend just starting from the default. The example default_config.json is an example of a config file with all default 
settings, but these are also listed here:

rayfile_directory: "/projects/<username>"
This is where you want the output of the raytracer to go. I'd stick with your projects directory on the supercomputer. 

date_time_iso_utc: "2019-04-21T12:00:0.0Z"
This needs to be filled out in iso_utc format.
More info here: https://en.wikipedia.org/wiki/ISO_8601

minalt: 500e3
This is the minumum altitude above the Earth's surface that the raytracer will trace to. This is in METERS. The radius of the Earth
is a assumed a constant 6371.2e3 meters. This is one of the 6 ways for the raytracer to stop tracing a ray (see list at end of document).

Kp: 1
This is the geomagnetic activity index, and will determine where the plasmapause is. Goes from 1 (quiet) to 9 (stormy)
More info here: https://www.swpc.noaa.gov/products/planetary-k-index

Ae: 1.6 
Another index of activity. This is the auroral electrojet index.
More info here: https://www.ngdc.noaa.gov/stp/geomag/ae.html

Pdyn: 4
Solar wind dynamic pressure, between 0.5 and 10 nPa. Used for the tsyganenko solar wind parameters. 
More info here: https://ccmc.gsfc.nasa.gov/models/modelinfo.php?model=Tsyganenko%20Magnetic%20Field

Dst: 1.0
Distrubance-storm-time index, in nT. Between -100 and +20 nT. Used for the tsyganenko solar wind parameters. 
More info here: https://ccmc.gsfc.nasa.gov/models/modelinfo.php?model=Tsyganenko%20Magnetic%20Field

ByIMF: 0.0
Interplanetary magnetic field in y direction. Between -10 and +10 nT. Used for the tsyganenko solar wind parameters.
More info here: https://ccmc.gsfc.nasa.gov/models/modelinfo.php?model=Tsyganenko%20Magnetic%20Field

BzIMF: -5
Interplanetary magnetic field in z direction. Between -10 and +10 nT. Used for the tsyganenko solar wind parameters.
More info here: https://ccmc.gsfc.nasa.gov/models/modelinfo.php?model=Tsyganenko%20Magnetic%20Field

W: [0.132, 0.303, 0.083, 0.070, 0.211, 0.308]
Coefficients used by the tsyganenko model. 

use_tsyg: 1
1 to use the tsyganenko model, 0 to not use it.

use_IGRF: 1
1 to use IGRF magnetic field, 0 to use simple dipole model. Currently (09-2021) IGRF-13 is in use.
More info here: https://www.ngdc.noaa.gov/IAGA/vmod/igrf.html

t_max: 10
Maximum time in seconds for a ray to propagate in the magnetosphere. This is one of the 6 ways for the raytracer to stop tracing a ray (see list at end of document).
This is not related to simulation time, this is the actual time the ray is propagating. 10 seconds is usally plenty, 
but if you want a lot of reflections or you think the ray might encounter some really intense gradients, consider increasing this. 

dt0: 1e-3
Ray tracer uses adaptive time stepping. This is the initial time step in seconds. If you want to use fixedsteps,
you can set fixedstep to 1. This timestep will then be the timestep used throughout the ray's path.
More info here: https://en.wikipedia.org/wiki/Adaptive_step_size

dtmax: 0.1
Maximum allowable time step in seconds. Anything larger might have some pretty big errors, and if you want to increase 
accuracy / number of steps, try decreasing this. 

root: 2
This is the root of the appleton hartree equation. 2 = whistler. 
More info here: https://en.wikipedia.org/wiki/Appleton%E2%80%93Hartree_equation

fixedstep: 0
Use fixed steps (1) or adaptive timesteps (0). Fixed steps have NO way to recover if you pop outside the 
resonance cone, so adaptive is always recommended.

maxerr: 5.0e-3
Error bound for adaptive timestepping. If the error gets to this value (often near resonance cone) the timestep will refine down.

maxsteps: 5e3
Maximum number of time steps. This is one of the 6 ways for the raytracer to stop tracing a ray (see list at end of document). Try increasing if 
your rays are hitting this wall. 

outputper: 1
Output only every “outputper” timesteps (reduces output file size). 1 = output every time step. If file size is a concern,
or if you don't care as much about the ray path, change this to 10 or something like that (for context, most rays take several
thousand steps).

mode: "DE"
modes that are working right now: Diffusive Eqiulbrium ("DE") and simplified GCPM ("GCPM"). DE seems to work a little better, 
or atleast the results are more explainable. 

Diffusive Eqiulbrium is described by this paper: 
Angerami, J., & Thomas, J. (1964). Studies of planetary atmospheres: 1. the dis-
tribution of electrons and ions in the Earth’s exosphere. Journal of Geophysical Research, 69 (21), 4537–4560.

GCPM by this paper: Gallagher, D. L., Craven, P. D., & Comfort, R. H.(2000). Global core plasma model.
Journal of Geophysical Research: Space Physics, 105 (A8), 18819–18833.

the simplified version of GCPM that is implemented is described in Austin Sousa's thesis: 
Sousa, A. P. (2018). Global and seasonal effects of lightning-induced electron precipitation. Stanford University.

And finally, the rays. 

Each ray is added with the following input parameters: 
alt: 1000e3 
start altitude in METERS from Earth’s surface. The radius of the Earth is a assumed a constant 6371.2e3 meters.

lat: 50
start latitude in geographic coordinates in degrees (NOT GEOMAGNETIC)

lon: 0
start latitude in geographic coordinates in degrees (NOT GEOMAGNETIC)

freq: 5e3
frequency of the ray in Hertz

alpha: 0
initial wavenormal angle in degrees (angle between the magnetic field and the ray direction). the ray tracer is in 3 dimensions
so this angle means the same wavenormal actually traces out a cone around the magnetic field line
an alpha of 10 degrees would be a small 10 degree cone around the bfield line, while 50 degrees is a much larger cone. 
the ray could be anywhere on the surface of this cone, with phi (degrees) setting the azimuthal angle on that cone.
a phi of 0 is in the meridional plane.
This is from 0 to 360, but keep in mind that anything from 90 deg to 270 deg is going to go the other way. 
Keep in mind that the Bfield points from south geographic pole to north geographic pole. So if you're starting a ray in the northern hemisphere and 
you want it to go south with a wavenormal of 10 degrees, set the 

field-aligned (going south): alpha = 0, phi = 0
field-aligned (going north): alpha = 180, phi = 0
 

phi: 0
see above 

Stop condition list.
The raytracer will stop if: 
1. min altitude reached (minalt)
2. dt too small (less than 1e-14 seconds). Try adjusting maxerr (lower) and dt0 (lower), or use fixed steps. 
3. nonsensical group velocity - faster than speed of light. sometimes happens outside the plasmapause.
4. k=0. nonsensical k vector. this is not phyiscal.
5. maxsteps hit (maxsteps)
6. max time hit (t_max). Again, not simulation time, but ray time.
